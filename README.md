# python-temperature-unit-converter
A Python OOP project demonstrating temperature conversion from Celsius to Fahrenheit and Kelvin using classes, instance attributes, methods, and mathematical formulas.
<br>
Topics Covered:
<br>

1. Class and Object
2. Constructor (__init__())
3. Instance Attributes
4. Instance Methods
5. self Keyword
6. Mathematical Operations
7. Temperature Conversion Formulas
8. Return Statement
9. F-String Formatting
10. Docstrings
